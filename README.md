# Rain Education V23 Review Draft

This branch contains the current V23 homepage draft for review only.

It is not deployed to the live website.

## Context

Rain Education is repositioning the homepage away from a video-led or animation-led presentation and back toward a premium education consulting brand:

- high-end education consulting group
- Hong Kong academic pathway planning
- international admissions advisory
- long-term GPA and academic strategy management

## Review Focus

Please review whether the homepage communicates:

- premium, restrained, international consulting quality
- strong Hong Kong-to-global-universities positioning
- credibility without sounding like a low-end admissions agency
- clear pathway logic for associate degree, undergraduate, postgraduate and global top university planning
- better visual hierarchy, copy quality, trust signals and conversion flow

## Important

This is a draft for feedback. It should not be treated as the final production homepage.

The visible homepage is the current `index.html` with the V23 premium consulting CSS override at the top of `styles.css`. Some older unused CSS selectors and JavaScript guards from previous iterations may still exist in the files, but the current homepage DOM does not use the old video hero, map route animation, canvas animation or offer wall sections.

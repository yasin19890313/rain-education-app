# Rain Education Website Design Rules

最后更新：2026-06-19

这份文件是 Rain Education 官网设计规范。任何新设计、新页面、新组件或首页大改，都必须先对照本文件。

## 1. 整体设计定位

官网应呈现：

- 高端。
- 国际化。
- 香港教育咨询集团气质。
- 深蓝、黑金、白色、香槟金的高级感。
- 咨询公司式信息架构、案例逻辑和克制视觉。
- 可信、专业、学术、长期规划。

官网不是：

- 普通留学中介。
- 招生模板站。
- 纯视觉展示站。
- 视频展示站。
- 科技感动画站。
- 短内容落地页。

参考气质可以接近 Oxbridge Applications、IvyWise、Crimson Education、McKinsey、Bain 这类“专业可信、信息完整、转化清晰”的方向，但不得照抄任何站点。

## 2. 首页规则

首屏规则：

- 首屏不放视频。
- 首屏不使用品牌宣传片。
- 首屏不使用地图飞线、粒子、路线动画、HUD 或过度科技感元素。
- 首屏应使用高质量静态视觉、品牌文案和核心 CTA。
- 首屏要体现 Rain Education 的高端感、香港起点、全球路径和专业度。

首屏建议结构：

- 左侧：核心主张、英文副标题、专业说明、两个 CTA。
- 右侧：香港维港、香港城市天际线、港校或学术场景高质量图片。
- 可使用轻玻璃拟态信息卡，但不应覆盖大面积文字卡片。

内容规则：

- 首页不能太空。
- 不能为了视觉删掉核心转化内容。
- 不能把完整官网改成几个模块的短版咨询模板。
- 数据、服务、路径、案例、导师、信任中心、家长痛点、SEO 入口、咨询表单和联系方式都应保留。

## 3. 内容规则

必须突出：

- 公司核心产品。
- 港八副学士 2+2+1 名校跃升计划。
- 港九大本硕连读精英规划计划。
- 香港本科申请。
- 香港硕士申请。
- 英国 G5 与牛剑方向。
- 新加坡申请。
- GPA 管理与背景提升。
- 长期升学战略规划。
- 升学结果与规划能力。

必须保留足够内容深度：

- 产品卡片不能只写一句话。
- 成功案例不能只堆 logo 或 offer 图，应解释学生背景、挑战、规划路径、最终结果和 Rain Education 的支持。
- 导师团队不能只做极简列表，应展示照片、学校背景、专业方向和擅长领域。
- 家长痛点、FAQ、信任中心和咨询表单是转化基础，不得随意删除。

不允许：

- 删除用户已经明确要求保留的重要内容。
- 用泛泛的“专业团队、优质服务、名校申请”替代具体服务体系。
- 把真实 offer、导师、路径、表单等高价值内容藏得太深。

## 4. 图片与视觉素材规则

图片要求：

- 所有图片必须高清。
- 不允许模糊低清素材。
- 不允许拉伸变形。
- 不允许 Logo 变形。
- 城市背景要高级，不能廉价。
- 图片应使用合理尺寸和压缩格式，兼顾加载速度。

可使用素材方向：

- 香港维港。
- 香港城市天际线。
- 香港大学、香港科技大学、香港中文大学、香港城市大学、香港理工大学等港校校园。
- 课堂、图书馆、学术空间。
- 伦敦、纽约、新加坡、波士顿等全球教育城市。
- 世界名校相关视觉，但需注意版权和素材来源。

使用原则：

- 图片作为辅助，不是主角。
- 主角是学生、路径、规划、结果和可信服务。
- 首屏图片不要暗到看不清，也不要被大面积遮罩压住。
- 手机端图片必须裁切合理，不得压缩变形。

## 5. 文案规则

文案要像高端咨询公司：

- 准确。
- 克制。
- 有判断力。
- 有路径感。
- 有风险意识。
- 有转化力。

应强调：

- 规划。
- 路径。
- 陪伴。
- 策略。
- 结果。
- 家庭决策支持。
- GPA 与学术表现长期管理。

应避免：

- 低端招生广告口吻。
- “包录取”等高风险表达。
- 夸张违法承诺。
- 空泛口号堆砌。
- 过度制造焦虑。

合规提示：

- 结果类内容要加边界说明。
- Offer、案例、升学率等内容应避免泄露学生隐私。
- 服务承诺以正式协议为准。

## 6. 移动端规则

手机端必须优先检查：

- 导航不能拥挤。
- 菜单按钮必须清晰可点。
- CTA 按钮不能太小。
- 文字不能过密。
- 图片不能压缩变形。
- 首屏高度要合理，不能只看到巨大的空白或被导航压住。
- 数据卡片必须一张一张清楚展示，不能横向挤压。
- 表单输入项要足够大，便于手机填写。

移动端检查最低断点：

- 390px 宽度。
- 768px 宽度。
- 1024px 宽度。
- 1440px 桌面宽度。

每次大改后至少验证：

- 是否有横向滚动。
- 标题是否换行合理。
- CTA 是否在首屏可见。
- 表单是否可填写。
- 图片是否清晰且不变形。

## 7. 禁止回退方向

以下方向用户已明确否定，后续不要恢复：

- 首屏品牌宣传片视频。
- 首页视频展示站方向。
- SVG 航线动画。
- 地图飞线。
- 地图节点动画。
- 粒子动画。
- 科技感 HUD。
- 内容很少的短版咨询模板。
- 只为了高级感而删掉服务内容。
